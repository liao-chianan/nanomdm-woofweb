資料庫維護 — nanomdm 指令歷史清理

每次派送給裝置的 MDM 指令、裝置的回應紀錄,都會累積在 nanomdm 的資料庫裡。 這裡可以設定保留天數,超過保留天數的指令紀錄會被清除,避免資料庫無限成長。 還沒完成的指令只要有近期連線過的裝置在等,就會保留(裝置可能已經收到、還沒回報,刪掉會讓裝置卡住); 只有排了這個指令的裝置都超過保留天數沒連線(例如長時間離線、清除重置)時才會清除, 這類裝置之後上線不會再收到,請自行確認狀況,需要時重新派送。

電子書下載IP範圍限制

群組派送電子書時,iPad 會用網址 https://本機網域/ebooks/(隨機檔名) 自己下載檔案。 iPad 下載時不會帶任何登入資訊,所以只要知道網址、而且來源 IP 在下面允許的範圍內,任何裝置都可以下載。 設定 IP 範圍(CIDR 格式,例如 192.168.0.0/16 或單一 IP 203.0.113.5)可以只讓學校網路下載。 清單留空代表不限制,任何來源都可以下載。

⚠️ 風險與責任:
  • 不限制 IP 時,網址一旦外流(例如被轉貼),校外任何人都能下載這些檔案。檔名是隨機長字串、無法猜到,也無法列出所有檔案,但這不等於加密或權限控管。
  • 限制 IP 時,iPad 不在允許範圍內(例如帶回家)剛好收到派送,會下載失敗,回到學校後要重新派送。
  • 請只上傳學校有權散布的教材。有版權、個資或內部資料的檔案,請務必限制 IP,或不要用這個方式派送;上傳與派送內容的著作權與個資責任由學校與管理者自行負責。
  • IP 判斷以連到這台伺服器時看到的來源 IP 為準。學校對外如果經過 NAT,校內 iPad 看到的通常是學校的對外 IP,請依實際網路環境設定。
